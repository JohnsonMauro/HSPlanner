# Screenshot assets

Orphan branch. No app code lives here — only images referenced from pull request
bodies, one folder per feature.

Raw URL shape:

```
https://raw.githubusercontent.com/JohnsonMauro/HSPlanner/assets/screenshots/<feature>/<file>.png
```

These URLs stop resolving if this fork is deleted or renamed. For a PR that has
to outlive the fork, drag the images into the PR body in the browser instead so
GitHub rehosts them under `user-attachments`.
